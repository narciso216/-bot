# 庄邊聊聊｜客庄文化夥伴

可直接部署至 Vercel 的靜態網站原型，沒有建置步驟：將此資料夾推送到 GitHub，在 Vercel 匯入專案並部署即可。也可直接以瀏覽器開啟 `index.html` 預覽。

## 原型功能

- 客庄主題聊天：辨識情感、客庄文化、一般話題，分別培養親暱度、理智分、可愛分；每日合計最多增加 30 點。
- 每日答題：每日 10 題，答對一題 +10 知識積分。
- 知識擂台：10 題、逐題累積競技積分；獲勝額外 +15 知識積分，平手不發放勝利獎勵。原型以本機模擬對手演示流程，雙方不互傳訊息。
- 角色衣櫃：以知識積分兌換裝扮；部分裝扮需先達到屬性門檻。
- 三屬性進度條、共同稱號與瀏覽器本機登入資料。

## 部署

在 Vercel 選擇 **Add New → Project**，匯入 GitHub 儲存庫，Framework Preset 選 **Other**，Build Command 留空，Output Directory 設為 `.`。此資料夾內的靜態檔案即可部署。

## 正式上線前

目前登入只是本機展示流程，使用者資料與遊戲進度存在瀏覽器 `localStorage`，無法跨裝置同步，也不是安全的帳號驗證。公開服務需接入 Supabase/Firebase 等身分驗證、資料庫與伺服器端積分驗證；真正兩人 PK 需採伺服器配對與同步作答。聊天回覆目前使用內建知識與規則分類，若要接大型語言模型，API 金鑰必須放在伺服器端，避免暴露在瀏覽器。
